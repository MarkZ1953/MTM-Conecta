# MTM Conecta

MTM Conecta es una plataforma web desarrollada para optimizar la gestión administrativa y social de la Fundación MTM.  
El sistema centraliza la administración de beneficiarios, donantes, proyectos, donaciones y procesos internos, mejorando la organización, trazabilidad y control de la información.

---

## 🎯 Objetivo

Facilitar la gestión integral de la Fundación MTM mediante una herramienta digital que permita:

- Registrar y administrar beneficiarios
- Gestionar donantes y donaciones
- Controlar proyectos y actividades sociales
- Administrar usuarios y roles
- Generar reportes y métricas de impacto

---

## 🚀 Características Principales

- Gestión de beneficiarios
- Gestión de donantes
- Registro y seguimiento de donaciones
- Administración de proyectos sociales
- Sistema de roles y permisos
- Reportes administrativos
- Control de trazabilidad de información

---

## 🏗️ Arquitectura

El sistema está diseñado bajo una arquitectura cliente-servidor:

- Backend: API REST
- Frontend: Aplicación web interactiva
- Base de datos relacional
